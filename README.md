# Pops Support

Support and privacy policy pages for the Pops iOS app, served by GitHub Pages:

- https://cleevao.github.io/pops-support/
- https://cleevao.github.io/pops-support/privacy-policy.html

Edit `FAQ.md` and `privacy-policy.md`; the pages load them. Preview locally with `python3 -m http.server 8000`.
